# Superpositions, Sudoku, the Wave Function Collapse Algorithm

> [!summary]
> A popular video that explains WFC by comparison with solving a Sudoku, then
> shows how to use it with 3D modules modelled in Blender and assembled in
> Godot. It covers how to describe which modules may touch using face sockets,
> and how to generate the rules automatically instead of writing every pair
> by hand. Christian Mills published written notes on the video that are
> quicker to skim.

## Citation

Martin Donald. 2020. Superpositions, Sudoku, the Wave Function Collapse
algorithm. Video, YouTube. <https://www.youtube.com/watch?v=2SuvO4Gi7uY>

Written notes: Christian Mills. 2021. Notes on WaveFunctionCollapse for 3D.
<https://christianjmills.com/posts/wave-function-collapse-for-3d-notes/index.html>

Link only: a video and a web page; neither may be redistributed.

## Why it matters here

It is the one widely known walk-through that uses Godot, and it follows the
same socket convention as [[kleineberg-2019-infinite-city-wfc]], which the
project adopts. A good first watch before reading the tileset format.
