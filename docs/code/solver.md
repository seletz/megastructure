# Solver

> [!summary]
> The solver is the part of the fill layer that decides which tile goes into
> each 2 m cell of a sector. It takes the tile library (every rotated tile
> and which tiles may touch in each direction) and a grid size, and for a
> seed and a sector returns one tile index per cell, with every pair of
> neighbours allowed. Everything it chooses comes from the shared hash, so
> the same seed and sector always give byte-identical output. A check task
> solves small grids twice, compares them with a recorded reference and
> times a full 24³ sector. Restarts after a failed attempt, cells fixed by
> the walkable graph and fixed sector faces come in the next issues.

## Files

- [sector_solver.gd](../../scripts/world/sector_solver.gd) (`class_name
  SectorSolver`, a `RefCounted`): the solver, with the inner class `Result`.
- `scripts/tools/solver_check.gd`: the check behind `mise run
  solver-check`, listed in [[tools-and-tasks]].
- [[solver_reference_seed0]]: the recorded SHA-256 of the seed 0 output,
  generated by `mise run solver-check --update`.

## Using it

```gdscript
var library := TileLibrary.build(load("res://resources/tilesets/placeholder.tres"))
var solver := SectorSolver.new(library, Vector3i(24, 24, 24))
var result := solver.solve(seed, sector)
if result.ok:
	var tile := library.tiles[result.cells[solver.index(Vector3i(3, 0, 5))]]
	print(tile.label(), " after ", result.steps, " steps in ", result.time_usec, " us")
else:
	printerr(result.error)    # "contradiction at cell (2, 23, 4)"
```

| `SectorSolver` member | Meaning |
| --- | --- |
| `new(library, grid_size)` | Builds the tables for a valid `TileLibrary` and a grid, default 24³. Reuse one solver for many solves of the same size. |
| `size` | Cells per axis. |
| `use_entropy` | Choose the next cell by Shannon entropy instead of fewest tiles left; off by default (decision #137). |
| `solve(seed, sector, domains)` | Fills the grid. `domains` (optional) holds `cell_count() * library.word_count` words ANDed into the starting domains, for pre-collapsed cells and fixed faces. |
| `cell_count()` | `size.x * size.y * size.z`. |
| `index(position)`, `position(cell)` | Cell index `x + size.x * (y + size.y * z)` and back. |

| `Result` field | Meaning |
| --- | --- |
| `ok` | Every cell holds exactly one tile. |
| `cells` | `PackedInt32Array` of tile indices in cell index order; empty unless `ok`. |
| `steps` | Observations: cells collapsed by a weighted draw. |
| `propagations` | Cells taken off the propagation queue. |
| `restarts` | Always 0 until restarts exist (#91). |
| `time_usec` | Wall time of the solve. |
| `contradiction_cell`, `error` | The cell whose domain became empty and a message, or -1 and "". |

A solver holds its working arrays between solves, so one instance must not
run two solves at once; give each worker thread its own. Salts, the
algorithm, measurements and why AC-3 was chosen over AC-4 are in
[[sector-solver]].

## How to run or check it

- `mise run solver-check` (part of `mise run check`) solves an 8³ grid with
  the placeholder tileset at seeds 0 to 4 on two instances and fails unless
  every solve succeeds, both agree, every adjacency is allowed and seed 0
  matches [[solver_reference_seed0]]; also checks the entropy flag and a
  `domains` restriction, prints tile histograms, steps and times, and times
  the first 24³ solve that succeeds among seeds 0 to 4 (about 0.65 s on the
  development machine).
- After an intended change of the output (solver, hash, tileset or
  adjacency), run `mise run solver-check --update` and commit the reference.
