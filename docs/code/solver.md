# Solver

> [!summary]
> The solver is the part of the fill layer that decides which tile goes into
> each 2 m cell of a sector. It takes the tile library (every rotated tile
> and which tiles may touch in each direction) and a grid size, and for a
> seed and a sector returns one tile index per cell, with every pair of
> neighbours allowed. Everything it chooses comes from the shared hash, so
> the same seed and sector always give byte-identical output. Before it
> solves, a domain builder narrows cells to what the walkable graph's
> records ask for (a stair here, a portal opening there), to the sector
> type's default elsewhere (solid in solid sectors, air in voids), and
> optionally to what fits next to a neighbour sector's fixed face. When an
> attempt paints itself into a corner the solver starts over with the next
> seed, up to 8 times, then fills the sector with solid and says so. A check
> task solves small grids twice, compares them with a recorded reference,
> tests restarts and records, and runs 20 real sectors; a second task runs
> the whole pipeline for any one sector.

## Files

- [sector_solver.gd](../../scripts/world/sector_solver.gd) (`class_name
  SectorSolver`, a `RefCounted`): the solver, with the inner class `Result`
  and the enum `Outcome`.
- [sector_domains.gd](../../scripts/world/sector_domains.gd) (`class_name
  SectorDomains`, a `RefCounted`): the starting domains from records, sector
  type and fixed faces.
- `scripts/tools/solver_check.gd`, `scripts/tools/solver_sector.gd` and
  `scripts/tools/solver_sector_run.gd` (`class_name SolverSectorRun`, the
  pipeline shared by both): the scripts behind `mise run solver-check` and
  `mise run solver-sector`, listed in [[tools-and-tasks]].
- [[solver_reference_seed0]]: the recorded SHA-256 of the seed 0 output,
  generated by `mise run solver-check --update`.

## Using it

```gdscript
var library := TileLibrary.build(load("res://resources/tilesets/placeholder.tres"))
var rasteriser := EdgeRasteriser.new(WalkableGraph.new(seed))
var built := SectorDomains.for_sector(library, rasteriser, sector)
if not built.error.is_empty():
	printerr(built.error)     # "Record(...) and Record(...) cannot touch across +y: ..."
	return
var solver := SectorSolver.new(library, Vector3i(24, 24, 24))
var result := solver.solve(seed, sector, built.words)
match result.outcome:
	SectorSolver.Outcome.SOLVED:
		var tile := library.tiles[result.cells[solver.index(Vector3i(3, 0, 5))]]
		print(tile.label(), " after ", result.attempts, " attempt(s) in ", result.time_usec, " us")
	SectorSolver.Outcome.DEGRADED:
		push_warning("sector %s degraded to solid" % sector)    # result.cells all solid
	SectorSolver.Outcome.FAILED:
		printerr(result.error)    # "inconsistent starting domains: cell (4, 2, 4) ..."
```

| `SectorSolver` member | Meaning |
| --- | --- |
| `new(library, grid_size)` | Builds the tables for a valid `TileLibrary` and a grid, default 24³. Reuse one solver for many solves of the same size. |
| `size` | Cells per axis. |
| `use_entropy` | Choose the next cell by Shannon entropy instead of fewest tiles left; off by default (decision #137). |
| `max_attempts` | Attempts before the all-solid degradation, default `DEFAULT_MAX_ATTEMPTS` (8), clamped to 1..`ATTEMPT_LIMIT` (100). |
| `solve(seed, sector, domains)` | Fills the grid. `domains` (optional) holds `cell_count() * library.word_count` words ANDed into the starting domains, for pre-collapsed cells and fixed faces; they are propagated once, then attempts run from them with restarts. |
| `OUTCOME_NAMES` | `"solved"`, `"degraded"`, `"failed"`, by `Outcome`. |
| `cell_count()` | `size.x * size.y * size.z`. |
| `index(position)`, `position(cell)` | Cell index `x + size.x * (y + size.y * z)` and back. |

| `Result` field | Meaning |
| --- | --- |
| `outcome` | `SOLVED` (an attempt filled every cell), `DEGRADED` (every attempt contradicted, every cell solid) or `FAILED` (bad arguments or inconsistent starting domains, no cells). |
| `ok` | Every cell holds exactly one tile: solved or degraded. |
| `degraded` | The cells are the all-solid degradation; records and faces are not kept. |
| `cells` | `PackedInt32Array` of tile indices in cell index order; empty unless `ok`. |
| `attempts` | Attempts run, 1 to `max_attempts`; 0 when the starting domains failed. |
| `restarts` | Attempts that ended in a contradiction. |
| `precollapsed` | Cells whose starting domain `domains` narrowed, ascending. |
| `steps` | Observations over all attempts: cells collapsed by a weighted draw. |
| `propagations` | Cells taken off the propagation queue over all attempts. |
| `time_usec` | Wall time of the solve, every attempt included. |
| `contradiction_cell` | The cell whose domain became empty in the last contradiction, or -1. |
| `error` | Why the solve failed; empty unless `FAILED`. |

| `SectorDomains` member | Meaning |
| --- | --- |
| `for_sector(library, rasteriser, sector, faces, support_radius)` (static) | The domains of a real 24³ sector: its type from the graph's skeleton, its records from the rasteriser. |
| `build(library, size, type, records, faces, support_radius)` (static) | The domains of any grid: record masks, sector default outside the support columns, fixed faces. `faces` is empty or six `PackedInt32Array`s in face order, each empty or one tile index (or -1) per boundary cell at `u + size_u * v`, u and v the other two axes in xyz order. |
| `words` | `cell_count * word_count` words for `solve`; empty on error. |
| `record_cells` | Cell index of every record, ascending. |
| `error` | The first record, pair or face that cannot hold, or "". |
| `apply_faces(library, size, domains, faces)` (static) | ANDs fixed faces into existing words; returns an error or "". |
| `tile_matches(tile, family, orientation)` (static) | Whether a tile may stand in a record's cell: same family, and for a stair or side portal opening the matching rotation. |
| `family_mask(library, family, orientation)` (static) | The tiles `tile_matches` accepts, as words. |
| `orientation_error(family, orientation)` (static) | Why an orientation does not suit a family, or "". |
| `SUPPORT_RADIUS`, `AUTHORED_YAW` | 1; stair 0 and portal opening 3. |

A solver holds its working arrays between solves, so one instance must not
run two solves at once; give each worker thread its own. Salts, the
algorithm, the record rules, the restart policy, measurements and why AC-3
was chosen over AC-4 are in [[sector-solver]].

## How to run or check it

- `mise run solver-check` (part of `mise run check`, about 11 s) solves an
  8³ grid with the placeholder tileset at seeds 0 to 4 on two instances and
  fails unless every solve succeeds at the first attempt, both agree, every
  adjacency is allowed and seed 0 matches [[solver_reference_seed0]]; checks
  the entropy flag and a `domains` restriction; checks restarts and the
  degradation on seed 14, inconsistent records failing fast with their
  error, consistent records holding in every solved result and a fixed
  face; times a 24³ solve with restarts; and runs 20 real stratum sectors at
  seed 0, printing solved, degraded and failed counts and mean attempts.
- `mise run solver-sector <x> <y> <z> [--seed N]` runs one real sector
  through skeleton, graph, rasteriser, domains and solver and prints the
  sector type, records, outcome, attempts, time, a family histogram and
  whether every record and adjacency holds.
  Negative coordinates work as they are: `mise run solver-sector -159 -47
  -548`.
- After an intended change of the output (solver, hash, tileset or
  adjacency), run `mise run solver-check --update` and commit the reference.
